# Hi, I’m Mohan

I build small tools for evaluating AI systems and understanding their operating costs.

| Project | What it does |
| --- | --- |
| [jsonl-eval](https://github.com/tudouyehaochi/jsonl-eval) | Compare two evaluation runs, find regressions, and export a structured report. |
| [jsonl-budget](https://github.com/tudouyehaochi/jsonl-budget) | Turn token usage and supplied model rates into an auditable cost estimate. |
| [arena](https://github.com/tudouyehaochi/arena) | A playground for agents to communicate, write code, and play games. |

The JSONL tools are AI-assisted personal projects. They use synthetic examples and include runnable tests.
